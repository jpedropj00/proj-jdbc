# Sistema de Consulta a Banco de Dados com JDBC e DAO

Este projeto consiste em uma aplicação Java desenvolvida para demonstrar o acesso a bancos de dados relacionais utilizando **JDBC (Java Database Connectivity)** e o padrão de projeto **DAO (Data Access Object)**.

O objetivo é separar a lógica de acesso aos dados das regras de negócio, tornando o código mais organizado, reutilizável e de fácil manutenção. A aplicação realiza operações de consulta ao banco de dados por meio de uma camada de persistência estruturada, utilizando boas práticas de desenvolvimento orientado a objetos.

## Tecnologias utilizadas

* Java
* JDBC
* Banco de Dados Relacional
* SQL
* Padrão de Projeto DAO
* Programação Orientada a Objetos (POO)

## Funcionalidades

* Conexão com o banco de dados via JDBC.
* Consulta de registros utilizando comandos SQL.
* Organização do acesso aos dados por meio do padrão DAO.
* Separação entre as camadas de persistência e aplicação.
* Tratamento de exceções e gerenciamento de recursos.

Este projeto possui caráter acadêmico e tem como finalidade o estudo da integração entre aplicações Java e bancos de dados, aplicando conceitos fundamentais de persistência de dados e arquitetura de software.
